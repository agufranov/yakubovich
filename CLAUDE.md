# Проект: агрегатор лотов с торгов по банкротству

Общие инструкции — [common-instructions.md](common-instructions.md).

## Что это

Информационный сайт: человек ищет лот (машина, квартира, спецтехника, что угодно),
изучает карточку и уходит по ссылке на электронную площадку, где покупает. Мы не
проводим торги. Второй этап, пока не в работе, — помощь с оформлением документов.

Конкуренты: tbankrot.ru, bankrotbaza.ru.

## Состояние

Планирование. Кода продукта нет. Текущий шаг и открытые вопросы — [PROGRESS.md](PROGRESS.md).

## Факты об источниках, проверенные запросами

Не переоткрывать заново — всё воспроизводится скриптом [tools/probe/](tools/probe/).

- **ГИС Торги** (`torgi.gov.ru`) — открытый REST, без авторизации, богатая структура
  с нормализованными атрибутами. **Банкротства в нем нет.** Есть арестованное
  имущество ФССП (`229FZ`) и приватизация — смежный товар для того же покупателя.
- **ЕФРСБ** (`bankrot.fedresurs.ru`) — отдает 401/403 роботам. Варианты: официальный
  веб-сервис по договору либо сбор лотов напрямую с ЭТП.
- **ЭТП** — 49 площадок по банкротству, публичного REST нет ни у одной, везде HTML.
  Но площадки не независимы: **14 из них работают на движке iTender с идентичными
  URL — это один коннектор**. Еще две группы по 3. Крупные (Сбербанк-АСТ, РАД,
  Фабрикант, МЭТС) — одиночки со своим кодом.
- **Номер сообщения ЕФРСБ есть на карточке лота ЭТП.** Канонический сквозной ключ
  доступен без доступа к самому ЕФРСБ — платный веб-сервис Федресурса не нужен для MVP.

## Решения, принятые по проекту

Менять их можно, но осознанно — за каждым стоит проверенная причина.

1. **Начинаем не с банкротства, а с ГИС Торги.** Он открыт, и на нем сквозной пайплайн
   отлаживается за дни, пока делаются коннекторы к ЭТП. Архив начинает копиться сразу.
2. **`lot` и `asset` — разные сущности.** Один объект продается несколько раз
   (повторные торги, публичное предложение). Не заложить сразу — переразбирать архив.
3. **Цены только в `numeric`**, из точных строковых полей источника. Никаких float.
4. **Документы лотов не храним** — только ссылки и метаданные. Иначе терабайты.
5. **Ничего не удаляем**, статус `archived`. Архив — главный невосстановимый актив:
   источники стирают завершенные лоты, задним числом его не собрать.
6. **Наблюдаемость коннекторов с первого дня.** Коннектор ломается молча, возвращая
   ноль записей. Алертить на аномалию объема, а не на исключения.
7. **Один язык — TypeScript.** Команда маленькая, два стека её разорвут.
8. **Коннекторы пишем на семейства движков, а не на площадки.** Один коннектор
   iTender = 14 площадок. Приоритет подключения — по объему лотов, не по числу
   площадок.

## Работа с чужими API

Главное правило: **чужой API врет молча.** Неизвестный параметр игнорируется, `size`
обрезается, за границей выдачи приходит 200 с пустым телом, под нагрузкой — HTML
вместо JSON. Ошибки при этом нет ни разу.

Проверять не то, что запросил, а то, что вернулось. Фильтр — подачей заведомо
бессмысленного значения (вернулся 0 — работает, вернулась полная выдача — игнорируется).

Ходим на чужие сайты: ограничение частоты, паузы с ростом, честный User-Agent.
ГИС Торги начинает отдавать 503 уже на сотнях запросов.
