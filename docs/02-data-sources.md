## 1. ГИС Торги — открыт, богат, но БЕЗ банкротства

**Главный вывод разведки: банкротства (127-ФЗ) в ГИС Торги нет.**

Перебрали 11 существующих типов торгов и проверили 10 гипотез о коде банкротства
(`127FZ`, `BANKRUPT`, `BANKROT`, …) — все дают 0 результатов. При этом фильтр рабочий:
заведомо неверный код тоже дает 0, а реальный (`ZK`) — упирается в потолок выдачи.

Существующие типы торгов:

| Код | Что это | Полезно нам |
|---|---|---|
| `229FZ` | Реализация имущества должников (ФССП, арестованное) | **Да, очень** |
| `1041PP` | Изъятое имущество, обращенное в собственность государства | Да |
| `178FZ` | Приватизация государственного и муниципального имущества | Да |
| `ZK` | Аренда и продажа земельных участков | Частично |
| `115FZ` | Концессионные соглашения | Нет |
| `ZHKH` | Отбор регоператоров ТКО и УК | Нет |
| `67FAS`, `67FAS_147FAS`, `APGU` | Аренда госимущества | Нет |
| `ZKPT`, `2499PP`, `1299PP` | Публичные торги по земле, недра, незавершенка | Частично |

Тип `229FZ` (>10 000 лотов) — это ровно тот же покупатель: в выдаче легковые
автомобили, спецтехника, доли в квартирах. Такие лоты агрегирует и tbankrot.

**Что дает API:** название, описание, начальная/финальная цена, шаг, дата окончания,
статус, регион, категория из государственного классификатора, код ЭТП, изображения,
вложения с хешами, ссылка на предыдущие процедуры, и — главное — массив
`characteristics` с **уже нормализованными атрибутами**: `vin`, `carMarka`, `carModel`,
`mileage`, `engineCapacity`, `yearProduction`, `cadastralNumberRealty`,
`totalAreaRealty`, `PermittedUse`. Государство уже сделало за нас работу по
структурированию — для этих лотов LLM-извлечение атрибутов не нужно вовсе.

**Роль в проекте:** источник №1 для запуска. Он бесплатный, без защиты, с богатой
структурой — на нем строится и отлаживается весь сквозной пайплайн, пока делаются
коннекторы к ЭТП. Плюс он самоценен как товар (229-ФЗ и приватизация).

## 2. ЕФРСБ — обязателен для банкротства, но закрыт

`bankrot.fedresurs.ru` — единый федеральный реестр сведений о банкротстве. Это
канонический источник: сообщения о торгах, сведения о должнике и арбитражном
управляющем, результаты торгов.

**Программный доступ заблокирован:** главная страница отдает 401, `fedresurs.ru` — 403,
внутренние backend-эндпоинты — 403 от nginx. Стоит антибот-защита.

Варианты доступа, по убыванию предпочтительности:

1. **Официальный веб-сервис Федресурса по договору** — легально, стабильно, платно.
   Требует переговоров и бюджета. Правильный путь при выходе на серьезные объемы.
2. **Не использовать ЕФРСБ на MVP** и собирать банкротные лоты напрямую с ЭТП.
   Логика: сам лот, документы и ссылка на покупку живут на ЭТП, а мы всё равно ведем
   туда пользователя. ЕФРСБ нужен для полноты и канонических ID — не для запуска.
3. Коммерческие API-прокси (parser-api.com, api-assist.com и подобные) — быстро, но
   это посредник без гарантий, юридически серая зона, зависимость от третьей стороны.

**Решение:** MVP делаем по варианту 2, параллельно прорабатываем вариант 1.

## 3. ЭТП — основной источник банкротства

~50 аккредитованных площадок. Работают по Приказу Минэкономразвития № 495 от 23.07.2015,
который обязывает оператора обеспечить круглосуточный открытый доступ и передачу
сведений в ЕФРСБ.

**Проверено: единого стандарта публичного API у них нет.** Ни один типовой путь не
отвечает. Площадки живые и доступны (m-ets.ru, centerr.ru, alfalot.ru, lot-online.ru,
utp.sberbank-ast.ru), но интерфейс выдачи данных у каждой свой и находится только
осмотром сетевых запросов их собственного фронтенда.

**Смягчающее обстоятельство:** значительная часть площадок работает на одном
White-label-движке (в частности, iTender). Один коннектор к такому движку закрывает
сразу несколько площадок. **Это ключ к экономике проекта** — вместо 50 коннекторов
реально нужно 8-12. Проверка этой гипотезы — первая задача этапа разведки.

Коды площадок, встречающиеся в ГИС Торги (готовый справочник для сопоставления):
`ETP_RTS`, `ETP_SBAST`, `ETP_EETP`, `ETP_RAD`, `ETP_AVK`, `ETP_TEKTORG`, `ETP_GPB`,
`ETP_MMVB`.

## Приоритеты подключения

| Очередь | Источник | Стоимость подключения | Что дает |
|---|---|---|---|
| 1 | ГИС Торги | 2-3 дня | Сквозной пайплайн + десятки тысяч лотов 229-ФЗ |
| 2 | Топ-3 ЭТП по объему | 1-2 недели | Ядро банкротных лотов |
| 3 | Движок iTender (пачкой) | 1 неделя | Длинный хвост площадок разом |
| 4 | ЕФРСБ по договору | переговоры | Полнота, канонические ID, данные о должнике |
| 5 | Остальные ЭТП | по мере роста | Заявка на полноту покрытия |
