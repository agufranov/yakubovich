Описание

Автоматический термосварочный станок для герметичной установки крышки, аккумулятора XDR-300 средней крышки. Автоматический термосварочный станок для герметичной установки малой, крышки аккумулятора XDR-300. Станок для сквозной сварки внутренних соединение XDC-600CY. Станок автоматического контроля электрических соединений XDW-600. Станок автоматической проверки герметичности XDQ -600. Станок для наполнения аккумуляторов А-100. Станок для нанесения цифровой кодировки на готовое изделие В-100. Плавильная печь с автоматическим контролем температуры HFG-300. Зарядно-нагрузочная станция ГФУ-600. Пила для разделения пластин HFG-300. Пневматический станок для внутренних отверстий XDK-600. Машина для смешивания паст HFG-300. Мельница для свинцового порошка EF-100. Предмет торгов, залог ПАО "Сбербанк".
