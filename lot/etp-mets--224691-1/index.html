Описание

Легковой автомобиль, марка: КИА JF (OPTIMA), год изготовления: 2019 г.в., цвет: Белый, VIN: XWEGT411BL0011007, ПТС: 23 PT 382273, г/н: Е859ХО08 Техническое состояние автомобиля удовлетворительное. Автомобиль на ходу. Резина зимняя. Двигатель, коробка передач (автомат) работают исправно. Рулевая система в порядке. Требуется замена тормозных дисков, колодок, масел, фильтров, расходников. Климат контроль, электроника в порядке. По кузову автомобиля имеются незначительные недостатки (на фото). На лобовом стекле имеется трещина, обзору не мешает. Автомобиль изъят у должника. По назначению не используется, не эксплуатируется. Находится под наблюдением финансового управляющего по адресу: г. Элиста Республика Калмыкия. Доступ для осмотра автомобиля обеспечен. Контактные данные для осмотра автомобиля: Финансовый управляющий Гучаев О.Б. (тел. 89064376979)
