ОпубликованПриватизацияТоргиДревесина

Описание

Количество и породный состав древесины: всего – 2141 куб.м., из них: хлысты из сосны – 483 куб.м., хлысты из ели – 271 куб.м., хлысты из лиственницы – 1194 куб.м., хлысты из кедра – 82 куб.м., хлысты из березы – 59 куб.м., хлысты из осины – 52 куб.м.
