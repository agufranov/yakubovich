# Скрипты разведки источников

Одноразовые скрипты для изучения чужих API. Не часть продукта — их задача проверять
факты, на которых построен план, и переподтверждать их, когда источник изменится.

## Зачем хранить в репозитории

Выводы в [docs/research/](../../docs/research/) написаны по результатам их работы.
Источники меняются молча — через полгода единственный способ понять, что именно
изменилось, это перезапустить ту же проверку и сравнить.

## Запуск

```bash
python tools/probe/gis_torgi_probe.py
```

Зависимостей нет, только стандартная библиотека.

## Важно про TLS

Скрипты **отключают проверку сертификата**, потому что госсайты используют сертификаты
российского УЦ, отсутствующие в стандартных хранилищах доверия.

Для разведки это приемлемо. **В боевых коннекторах — недопустимо**: там корневой
сертификат ставится в образ. См. [docs/research/grabli.md](../../docs/research/grabli.md).

## Методика

Главный урок разведки: **чужой API врет молча.** Неизвестный параметр игнорируется,
`size` обрезается, за границей выдачи возвращается 200 с пустым телом, под нагрузкой
приходит HTML вместо JSON — и ни в одном случае нет ошибки.

Отсюда правило для любой новой проверки: не верить тому, что запросил, — смотреть,
что реально вернулось. Фильтр проверяется подачей заведомо бессмысленного значения,
размер страницы — подсчетом фактических элементов, а не значением параметра.
